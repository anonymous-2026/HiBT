This directory exports the retained shared-goal protocol. Evaluation membership, instruction/state/goal/registry values, model prompts, learning objectives, budgets, and success tests are preserved. Changes are limited to relative vendor lookup, user-provided service/model paths, delayed imports for --help, metadata path anonymization, rebuilt portable-file hashes, and removal of an unsupported data-builder CLI branch. Each training stage retains its own formatter. Generated run configurations are new immutable runs; they never append to the archived runs. Upstream cached registry values remain unchanged. Hardware and checkpoint availability are not implied by a successful CPU check.
